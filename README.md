# Study Mate

A Python-based study assistant designed to help users stay focused and organized during study sessions.

The program provides a study timer where users can set their preferred session duration, a To-Do List for managing tasks, and an integrated Translator so users can translate text without leaving the application.

**Features**

**Study Timer**

- User name input and personalized messages
- Custom study session duration
- Support for seconds, minutes, and hours
- Pause and resume functionality
- Motivational messages during the study session
- Alarm notification when the session ends

**To-Do List**

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save the current task list
- Load previously saved tasks

**Translator**

- Translation between multiple languages
- Text-to-speech for input text
- Text-to-speech for translated text
- Save translations
- Translation history
- Integrated directly into the study application

**How to Run**

1. Open the project folder in Visual Studio.
2. Make sure all project files and folders are kept in their original structure.
3. Run `study.py`.
4. Enter your name to start using Study Mate.
5. Choose a study session duration and explore the available features.
